# 路线图

> 状态：☑️ 完成 · 🔄 进行中 · ⬜ 未开始。每项完成时同步补测试。

## M0：工程化跑通（☑️ 本次）

- ☑️ 原生 Android 工程：Kotlin + Compose、单 Activity、Gradle 版本目录
- ☑️ 设计令牌（颜色 / 间距 / 圆角 / 字体 / 主题）+ 对比度测试
- ☑️ 主界面：Bot / 群聊列表、搜索、新建面板、空态 / 错误态
- ☑️ Bot 对话占位页与导航
- ☑️ 启动图标：由 `design/app-icon-source.png` 生成 legacy + adaptive + 圆形
- ☑️ 单元测试（时间、颜色算法、状态、令牌、图标资源）
- ☑️ Compose 插桩测试
- ☑️ APK 可构建、可安装

## M1：接入 DSH（🔄 下一步）

- ⬜ 主机连接与登录：地址 + 启动 token 换 cookie；连接状态与错误提示
- ⬜ 会话列表 / 会话详情 / 新建会话
- ⬜ 聊天：发送、流式输出（SSE）、停止、历史分页
- ⬜ 模型选择、审批 / 提问卡片（原生渲染）
- ⬜ 本机远程（局域网 / SSH）优先；本机 PRoot 引擎后续
- ⬜ 契约测试：模拟 DSH 服务端（MockWebServer）覆盖正常 / 断线 / 超大消息 / 取消

## M2：DS Bot 团队

- ⬜ `BotRepository` 接入 DS Bot `state` + `feed`（revision 增量、断线补发）
- ⬜ 私聊 / 群聊 / @ 成员 / 未读与通知
- ⬜ Bot 详情：模型、记忆、用量、删除 / 设为主 Bot
- ⬜ 群详情：成员、管理员、公告、审批
- ⬜ 新建 Bot / 新建群聊
- ⬜ 与 DS Bot 手机接口版本协商（`hello` / `capabilities`）

## M3：本机引擎与多主机

- ⬜ 移植 dsh-Go 的 Kotlin 运行时层（PRoot 内跑 DSH）
- ⬜ 主机切换（本机 / SSH / Remote）
- ⬜ 后台保活、系统通知、通知直达会话

## M4：体验与发布

- ⬜ 深色主题打磨、动效、无障碍
- ⬜ 诊断日志与崩溃上报
- ⬜ 正式签名、应用内更新、发布流程
